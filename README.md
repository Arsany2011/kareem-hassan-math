# منصة كريم حسن للرياضيات

قالب بداية باستخدام React + Vite وThree.js عبر React Three Fiber.

## التشغيل

1. ثبّت Node.js بإصدار حديث.
2. افتح مجلد المشروع في VS Code.
3. شغّل:

```bash
npm install
npm run dev
```

4. افتح عنوان localhost الذي يظهر في الطرفية.

## بناء نسخة النشر

```bash
npm run build
npm run preview
```

## الهيكل

- `src/components/3d`: المشهد والرموز والمجسمات ثلاثية الأبعاد.
- `src/components/layout`: الهيدر والفوتر.
- `src/components/forms`: نموذج طلب التسجيل ورسائل الخطأ.
- `src/pages`: صفحات الموقع.
- `src/services`: مكان توصيل المصادقة وقاعدة البيانات لاحقًا.
- `src/styles`: تنسيقات عامة ومكونات وصفحات.

## ملاحظات مهمة

- هذا هيكل جاهز للبدء، وليس منصة إنتاج مكتملة.
- نموذج التسجيل الحالي تجريبي ولا يحفظ البيانات في قاعدة بيانات.
- صفحة دخول المستر واجهة أولية فقط؛ لا تضع بيانات حقيقية أو تعتمد عليها للحماية قبل ربط مصادقة آمنة وقواعد صلاحيات في الخادم.
- أضف صورة/فيديو المستر بنفسك داخل `public/images` أو `public/videos`.
